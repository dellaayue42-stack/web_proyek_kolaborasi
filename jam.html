Hiasan Jam Dinding

PRODUK DAUR ULANG

Teknologi lama, fungsi baru

Memanfaatkan Hiasan Jam Dinding menjadi Hiasan yang unik dan estetik. Produk ini merupakan bentuk kreativitas dalam mengurangi limbah.

Alat

✓ Gunting dan Cutter.

✓ Jangka / Piring bundar.

✓ Penggaris dan pensil.

✓ Alat pembuat lubang / pelubang kardus.

Bahan

✓ Kardus tebal / karton.

✓ Sedotan plastik warna-warni.

✓ Mesin jam dinding beserta set jarum jam.

✓ Tali rami.

✓ Lem tembak / lem super.

Cara pembuatan

  1. Potong kardus menjadi bentuk lingkaran.
  2. Tempelkan sedotan warna warni di sekeliling lingkaran.
  3. Buat dan tempelkan angka serta hiasan bunga.
  4. Buat lubang dibagian tengah dan pasang mesin beserta jarum jam.
  5. Pasang tali pada bagian belakang agar jam dapat digantung.
  6. Periksa apakah jarum jam bergerak dengan baik.

Estimasi biaya:

  1. Alat:(tidak ada yang dibeli)
  2. Sedotan plastik : Rp 6.000, Baterai : Rp 4.000, Tali rami : Rp 4.000
  3. Total: Rp 3.000
  4. Harga Jual: Rp 30.000
  5. Laba: Rp 30.000 - 14.000 = Rp 16.000
