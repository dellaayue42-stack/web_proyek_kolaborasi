Hiasan Meja dari Keyboard Bekas

PRODUK DAUR ULANG

Teknologi lama, fungsi baru

Memanfaatkan Keyboard bekas menjadi Hiasan meja yang unik dan estetik. Produk ini merupakan bentuk kreativitas dalam mengurangi limbah.

Alat

✓ Penyungkil atau obeng minus kecil

✓ Pistol lem tembak

✓ Gunting/Cutter

✓ Lem perekat

✓ Penggaris

Bahan

✓ Tombol-tombol keyboard bekas

✓ Kawat atau batang

✓ Alas atau dudukan hiasan

✓ Dinamo

✓ Saklar Kecil

✓ Baterai

Cara pembuatan

  1. Siapkan keyboard bekas yang sudah tidak digunakan.
  2. Lepaskan tombol-tombol keyboard dengan hati-hati.
  3. Susun dan rekatkan tombol tersebut hingga membentuk bola.
  4. Pasang bola tombol keyboard pada batang penyangga.
  5. Buat dudkan yang kokoh agar hiasan dapat berdiri dengan baik.
  6. Rapikan hasil kerajinan agar terlihat menarik dan siap dipasang di atas meja.
